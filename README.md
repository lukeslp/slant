# Slant

A browser game by Luke Steuber.

This private repository preserves the committed source from [game-riffs](https://github.com/lukeslp/game-riffs/tree/7d12e797c85d3d8f4b6b477cefc8092c2a5383dc), snapshot October 11, 2026. Development and deployment continue there.

## Source

- [slant](slant/)

The original directory layout is retained so relative references and test entrypoints keep their meaning. Open a game directory through a local static server. Existing per-game documentation describes its controls and checks where available. Tests and reference material are source assets and do not belong in a public runtime payload.

`SOURCE.json` records the source revision, directories and SHA-256 of every copied file. This snapshot does not assert that every file matches the live release or that every test has been run.
